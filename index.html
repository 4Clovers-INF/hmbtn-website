About HMBTN

HMBTN is a community-driven technical project exploring the original PlayStation game through software decompilation and modding. The aim is to support deeper understanding of the game's code and provide a foundation for carefully developed modifications.

Project areas

Decompilation

Research and reconstruction of the game's software structure using the project source repository.

Modding

Technical exploration of ways to extend or modify game behavior while respecting original game systems.

Development

Source code and project work are maintained in the GitHub repository.
